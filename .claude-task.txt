COSA COSTRUIRE:

=== SERVIZIO: src/services/booking-slots.js ===
Funzione principale: computeBookingSlots(siteId, { days = 14 } = {})
- Legge da tenant_config le chiavi:
  * booking_slot_minutes (default: 60) — durata di ogni slot
  * booking_hours_start (default: "09:00") — ora di inizio finestra
  * booking_hours_end (default: "18:00") — ora di fine finestra
  * booking_available_days (default: "1,2,3,4,5") — giorni settimana (0=Dom,6=Sab)
  * booking_lead_time_hours (default: 1) — ore minime di preavviso
  * booking_window_days (default: 14) — giorni massimi nel futuro
- Computa slot: per ogni giorno da oggi per days giorni, se il giorno e tra i giorni disponibili, genera slot di booking_slot_minutes tra booking_hours_start e booking_hours_end
- Esclude slot nel passato o con lead time insufficiente
- Esclude slot che confliggono con booking_appointments esistenti (status non cancellato, sovrapposizione time range)
- Ritorna [{ start: Date, duration_minutes: number }]
- Funzione di utility: groupSlotsByDay(slots) — raggruppa per giorno (stesso pattern di calls.js ma esportata)

=== ROUTE: src/routes/booking-public.js ===
Router pubblico (nessun middleware auth/tenant):

1. GET /booking-public/:siteId
   - Verifica sito esiste (SELECT id, name FROM sites)
   - Computa slot con computeBookingSlots
   - Rende views/book/booking-public-index.ejs con { site: {id, name, slug: null, description: ""}, groups, error: null, layout: false }

2. GET /booking-public/:siteId/slots (JSON)
   - Stessa verifica sito
   - Ritorna { ok: true, groups: [...] } con groupSlotsByDay

3. POST /booking-public/:siteId
   - Rate limiter: { windowMs: 60000, max: 10, message: { error: "Troppe richieste" } }
   - Honeypot anti-spam (stessa logica di calls.js: _honeypot/website/url)
   - Valida: email, name, slot (start_time dal body come ISO string)
   - Calcola slot correnti e verifica che lo slot scelto sia valido (esiste tra gli slot calcolati)
   - Crea booking chiamando createBooking da ../services/booking.js
   - Se AJAX request (X-Requested-With o accept json): res.json({ ok: true })
   - Altrimenti redirect a /booking-public/:siteId/confirmed?email=...

4. GET /booking-public/:siteId/confirmed
   - Pagina di conferma (EJS) con { email, layout: false }
